Настроить автоматический запуск тестов.

3. Описание приложения
Приложение «Калькулятор среднего балла» принимает оценки от 0 до 100,
вычисляет среднее арифметическое и округляет результат до двух знаков.
Функция average_score реализует расчёт и проверку значений.
Пустой список, значения вне диапазона, нечисловые значения, NaN и бесконечность
вызывают ValueError. Консольный интерфейс сообщает об ошибках ввода.
Для примера 80, 90, 100 ожидаемый средний балл равен 90.00.

6. Конфигурация конвейера
Файл: .github/workflows/ci.yml
[Вставьте сюда полный текст ci.yml из проекта.]
Конвейер запускается при push, Pull Request или вручную.
Build получает код, настраивает Python 3.13, выполняет установку зависимостей
и компиляцию исходников в байт-код. Для Python это учебная проверка сборки,
а не создание exe-файла. Test выполняется после успешного Build и запускает
unit-тесты. Зависимость задана параметром needs: build.
Для чтения репозитория задано разрешение contents: read.

7. Результаты тестирования
Предусмотрено восемь тестов:
1. Среднее для 80, 90, 100 равно 90.
2. Среднее единственной оценки 75 равно 75.
3. Среднее граничных значений 0 и 100 равно 50.
4. Среднее для 80, 81, 81 округляется до 80.67.
5. Пустой список вызывает ValueError.
6. Оценки -1 и 101 вызывают ValueError.
7. Строка, None и логическое значение вызывают ValueError.
8. NaN и бесконечность вызывают ValueError.
